# Source art

Print-resolution originals and product mock-up masters. These are the source
files the web images were derived from - they are NOT meant to be served to
visitors and nothing on the site links to them.

Web-ready derivatives live in /site-img/ (and /site-img/merch/ for products).
This folder is excluded from the public site by a 404 redirect in netlify.toml
and by robots.txt.
